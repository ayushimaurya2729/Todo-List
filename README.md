A simple todo list web app built with HTML, CSS, and JavaScript.
You can add tasks, mark them as completed, and delete them.
Your tasks are saved in the browser, so they are still there after you refresh or close the page.
Its features are:
-Add new tasks using the input box and the "add task" button
-Click a task to mark it as completed and click again to undo
-Delete a task using its delete button
-Tasks are saved automatically using the browser's localStorage
-Empty tasks are not allowed
-Simple, clean layout that works on both desktop and mobile screens
